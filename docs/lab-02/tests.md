# TokTickIT Lab 2 — Test Plan

## Test Strategy

Tests are planned from the approved Acceptance Criteria before implementation is considered complete. The plan covers happy paths, invalid input, boundaries, ownership, failures, loading and empty states, responsive behavior, Attachment lifecycle, and multi-Requester behavior as required by the Lab handout.
